Política de Privacidad

Última actualización: 12 de junio de 2026

Esta aplicación de Discord recopila únicamente la información necesaria para proporcionar sus funciones y servicios.

Información recopilada

* IDs de usuarios de Discord.
* IDs de servidores (guilds).
* IDs de canales y roles cuando sea necesario para el funcionamiento de la aplicación.

Uso de la información

La información recopilada se utiliza exclusivamente para:

* Ejecutar los comandos de la aplicación.
* Almacenar configuraciones del servidor.
* Mejorar el funcionamiento del servicio.

Compartición de datos

No vendemos ni compartimos información personal con terceros, excepto cuando sea requerido por la ley.

Seguridad

Tomamos medidas razonables para proteger la información almacenada.

Contacto

Si tienes preguntas sobre esta Política de Privacidad, puedes contactar al desarrollador a través de Discord.
